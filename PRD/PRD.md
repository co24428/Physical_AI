| 항목 | 내용 | 항목 | 내용 |

| **문서 버전** | v1.0 | **작성 일자** | 2026.10 |

| **운영 환경** | 공장 폐쇄망 (인터넷 차단) | **카메라 구성** | 총 40대 (산업용 GPU PC 10대) |

## 1. 문제 정의 (Problem Definition)

* **배경 및 타깃 고객**
  * 제조 공정 내 품질 검사 자동화를 도입하려 하지만, 생산 품목이 빈번히 변경되거나 제품별 불량 유형이 상이하여 기성 범용 비전 솔루션 도입에 한계를 겪는 제조 기업.
* **핵심 페인 포인트 (Pain Points)**
  * **긴 개발 기간 및 외주 비용**: 부품/신제품 설계 변경 시마다 재학습에 장기간이 소요되며 지속적인 외주 유지보수 비용 발생.
  * **맞춤형 파이프라인 부재**: 고객사가 보유한 소량의 정상/불량 데이터셋 특성에 맞춰 유연하고 빠르게 자체 학습·배포 가능한 환경 부재.
  * **현장 제약 조건**: 초당 10개(부품당 50ms 이내 판정)의 고속 인라인 환경과 외부 인터넷 연결이 차단된 공장 내부 폐쇄망 보안 규정을 동시에 충족해야 함.

---

## 2. 사용자 시나리오 (User Scenario)

1. **데이터 등록 및 검증**
   * 공장 품질 관리자(User)가 검사 대상 부품의 정상품 이미지 및 대표 불량 샘플을 사내 학습 시스템에 등록 및 검증.
2. **데이터 파이프라인 및 맞춤 학습**
   * 내부 파이프라인을 통해 데이터 증강(Augmentation), 라벨 포매팅을 거쳐 경량 비전 AI 모델(약 100MB급) 맞춤 학습 수행.
3. **평가 및 배포 승인**
   * 검증 지표(정확도, F1-Score, 추론 레이턴시) 확인 후 현장 적용 모델 패키지(가중치 + 전처리 파이프라인) 최종 승인.
4. **엣지 PC 이식 및 실시간 추론**
   * 공장 라인의 엣지 산업용 GPU PC로 모델 바이너리 배포.
   * 카메라 40대에서 컨베이어 벨트를 통과하는 부품(초당 10개)을 캡처하고, 50ms 이내에 양/불량을 판정하여 배출기(Ejector/PLC)로 트리거 신호 송출.

## 3. 성공 지표 (Success Metrics)

| 구분 | 핵심 지표 (KPI) | 목표치 | 측정 방식 및 기준 |
| :--- | :--- | :--- | :--- |
| **품질/정확도** | 불량 유출률 (False Negative Rate) | **≤ 0.01%** | 불량품이 정상으로 오판정되어 통과된 비율 (미검률) |
| | 과검률 (False Positive Rate) | **≤ 0.5%** | 정상품을 불량으로 잘못 판정해 배출/정지된 비율 (오검률) |
| **성능/지연** | 추론 지연시간 (Latency) | **≤ 35ms** (기준 50ms) | 이미지 캡처 시점부터 PLC 판정 트리거 신호 송출까지 |
| | 처리량 (Throughput) | **≥ 10 FPS / 카메라** | 카메라 4대당 1대 PC 기준(총 40 FPS) 프레임 드랍 0건 |
| **운영/배포** | 모델 파이프라인 주기 | **≤ 24시간** | 데이터 수집/업로드부터 엣지 배포 패키지 생성 완료까지 |
| | 시스템 가동률 (Availability) | **≥ 99.9%** | 24시간 가동 기준 비정상 다운타임 월 40분 이내 |

## 4. 기술 스택 (Tech Stack)

* **엣지 추론 & 하드웨어 (Edge Runtime)**
  * **OS**: Ubuntu 22.04 LTS (Real-time 커널 지원)
  * **가속 런타임**: NVIDIA TensorRT, ONNX Runtime (FP16 / INT8 양자화)
  * **엣지 디바이스**: 산업용 GPU PC 10대 (NVIDIA RTX급 탑재, PC 1대당 카메라 4대 수용)
* **비전 입력 & I/O 인터페이스**
  * **컴퓨터 비전**: OpenCV (C++ / Python 바인딩)
  * **카메라 연동**: 산업용 카메라 SDK (GigE Vision / GenICam)
  * **PLC 통신**: Modbus TCP, OPC UA 또는 산업용 고속 디지털 I/O 보드
* **모델 아키텍처 (Model Architecture)**
  * **결함 탐지/분류**: YOLOv8-nano/small, MobileNetV4, EfficientNet-Lite
  * **소량 데이터 대응**: 비지도 이상치 탐지 (PatchCore, FastFlow 등 Anomaly Detection)
  * **모델 크기**: 50MB ~ 100MB 내외로 경량화 최적화
* **학습 및 MLOps 파이프라인 (Training & MLOps)**
  * **프레임워크**: PyTorch, TorchScript
  * **실험/버전 관리**: MLflow (실험 및 모델 가중치 레지스트리), DVC (데이터 버전 관리)
  * **배포 관리**: Docker 컨테이너 기반 엣지 배포 (공장 로컬 프라이빗 레지스트리)

## 5. 범위 & 비범위 (Scope & Non-Scope)

| 포함 범위 (In-Scope) | 제외 범위 (Non-Scope) |
| :--- | :--- |
| **맞춤형 학습 파이프라인**: 신규 부품 데이터 입력 시 사전 정의된 규격에 맞춰 자동 파인튜닝/학습 | **하드웨어 설치 공사**: 조명 지그(Jig) 제작, 카메라 브래킷 기계 가공 및 현장 전기 배선 작업 |
| **엣지 최적화 추론 엔진**: 영상 수집, 불량 분류, 결함 좌표 추출, 판정 신호(50ms 내) 출력 런타임 | **물리 배출 기계 제어**: 비전 시스템은 판정 신호(Trigger)만 전달하며 실린더 구동은 PLC 담당 |
| **현장 로컬 모니터링 UI**: 엣지 PC별 실시간 검사 통계(FPS, 불량률, 최근 불량 캡처 뷰어) | **퍼블릭 클라우드 연동**: 보안 및 폐쇄망 제약으로 외부 SaaS/클라우드 기반 실시간 추론 배제 |
| **폐쇄망 배포 체계**: USB 또는 내부 격리 LAN을 활용한 모델 바이너리 배포 및 불량 로그 백업 | **원자재 물성 분석**: 표면 결함 외 X-ray 또는 초음파 투과 검사 등 비비전 영역 비파괴 검사 |

## 6. 예상 ROI (Return on Investment)

### 1) 정량적 효과 (연간 기준)
* **인건비 절감**:
  * 기존 육안 검사자 3교대(라인당 2명 × 3교대 = 6명, 1인 연봉 4,000만 원 가정) 대체 시 **연간 약 2.4억 원 절감**.
* **손실 방지 비용**:
  * 불량품 유출로 인한 고객사 클레임, 전량 리콜, 재작업(Rework) 비용 감소 효과 **연간 약 0.8억 ~ 1억 원 상당 리스크 절감**.
* **투자 회수 기간 (Payback Period)**:
  * 초기 구축비: 산업용 PC 10대(1.2억) + 카메라/소프트웨어 = **약 1.5억 원**
  * 연간 비용 절감액: **약 3.2억 원**
  * **약 6~8개월 내 손익분기점(BEP) 달성**.
* **인프라 TCO 절감**:
  * 클라우드 방식(전용선 + 서버 + 저장 연 4.1억 원) 대비, 엣지 운영 시 **3년간 약 10.5억 원 인프라 비용 절감**.

### 2) 정성적 효과
* **검사 일관성 확보**: 작업자 피로도 및 야간 교대 시간에 따른 판정 편차(Human Error) 완전 제거.
* **신제품 양산(Ramp-up) 전환 단축**: 제품 변경 시 1~2일 내 새 모델 학습·적용으로 생산 유연성 극대화.
* **핵심 영업비밀 보호**: 100% 로컬 폐쇄망 운영으로 신제품 형상 및 CAD 설계 데이터의 외부 유출 원천 차단.
