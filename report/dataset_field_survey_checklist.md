## 0. 데이터셋 진단 요약

| 구분 | 관찰 결과 | 시사점 |
| :--- | :--- | :--- |
| 규모 | 클래스당 130장, 정상:불량 = 1:1 | 실제 불량률(통상 1% 미만)과 다름 → 평가 지표 설계 시 실제 불량률 반영 필요 |
| 중복 | 완전 동일 파일 8그룹(9장 중복), 유사 이미지 포함 시 실질 고유 이미지 불량 약 98장 / 정상 약 104장 | 실제 유효 표본은 더 적음 |
| 포맷 | 전부 640×640 RGB PNG, 메타데이터(EXIF 등) 없음, 채도 평균 3 수준(사실상 흑백) | 원본 해상도·비율 정보 없음 |
| 라벨 | 폴더명(정상/불량)만 존재. 결함 위치·유형·심각도 정보 없음 | 판정 기준·유형 분류 체계 필요 |
| 배경 | 배경 밝기 118~255로 편차 큼, 회색·흰색·연보라 톤 혼재 | 배경/조명이 촬영마다 다름 |
| 크기/위치 | 부품 면적이 화면의 6%~63%로 약 10배 차이. 부품이 화면 가장자리에 닿거나 잘린 이미지 다수(자동 측정 기준 정상 104장·불량 67장, 배경 그림자 영향 일부 포함) | 촬영 거리·화각이 고정되어 있지 않음 |
| 회전 | 0~360° 임의 회전 | 투입 자세 미고정 |
| 선명도 | **불량 89장 vs 정상 34장이 흐림**(업스케일 흔적) | 모델이 결함 대신 "흐림"을 학습할 위험 |
| 형상 | 나사 구멍이 타원형, 너트 외곽 비율이 늘어난 이미지 다수 | 실제 규격 대비 왜곡 여부 확인 필요 |
| 하위 도메인 | 불량 클래스에만 **아연도금(청회색) 너트 약 22장, 녹+관통 균열 너트 약 19장, 원거리 소형 촬영 약 21장**이 섞여 있음. 정상 클래스는 거의 모두 깨끗한 스테인리스 1종 | 모델이 "결함"이 아니라 "재질/녹/거리"로 판별할 위험(Shortcut) |

> ⚠ 기존 `factory_check_list.md`는 샘플 2장 기준으로 "1화면 1부품 중앙 배치", "모션 블러 없음", "밝은 단색 배경", "모노크롬 카메라"로 체크되어 있으나, 아래 전수 기입 결과와 일부 상충합니다(3장 참고).

## 1. 대상 부품(품종) 및 정상 기준

*데이터 근거: 정상 클래스는 단일 품종(스테인리스 사각 너트), 불량 클래스는 도금·녹·형상이 다른 여러 품종이 섞여 있음.*

* **[1-1] 검사 대상 너트 품종 수**
  - [ ] 단일 품종만 검사
  - [v] 2~5개 품종 → 무처리 회색 사각 너트, 아연도금 너트, 녹 발생 직사각 너트, 소형 너트 등 최소 3~4종 관찰
  - [ ] 다품종 혼류 (품종 전환 빈도: 판단 불가)
  - ⚠ 정상 클래스에는 사실상 1종만 존재 → **나머지 품종은 정상 데이터가 0장**

* **[1-2] 표면 처리 종류**
  - [v] 무처리/스테인리스 → 정상 130장 전부, 불량 약 89장
  - [v] 아연도금(청색 계열) → 불량 약 22장 (예: `synth_defect_2, 13, 18, 27, 45, 104`)
  - [ ] 흑색 산화피막
  - [v] 기타: 녹 발생 강재 → 불량 약 19장 (예: `synth_defect_3, 5, 23, 46, 56, 119`)
  - [ ] 도금 품종에도 정상품이 존재하는가? → **아니오. 도금·녹 품종의 정상 이미지 없음**

* **[1-3] "정상"의 허용 범위 (골든 샘플 정의)**
  - [v] 경미한 녹/변색 → **불량으로 취급** (녹은 불량 클래스에서만 관찰됨, 단 녹 단독인지 균열 동반 때문인지는 판단 불가)
  - [v] 가공 흔적(동심원 헤어라인, 나사산 그림자) → **정상으로 허용** (정상 이미지 전반에 존재)
  - [ ] 방청유·먼지·지문 → 데이터에서 관찰되지 않음 (판단 불가)
  - [ ] 경계선 정상품(허용 범위 내 미세 흠) → 정상 클래스에 해당 사례 없음

* **[1-4] 실제 형상 확인**
  - [v] 정사각형과 직사각형 외곽이 혼재, 모서리 챔퍼 있음
  - [v] 나사 구멍이 타원형인 이미지 다수 (특히 정상 클래스, 직사각 너트) → 실물 규격과 다를 가능성 높음

## 2. 결함 유형 및 분포

*데이터 근거: 불량 130장을 육안 분류한 근사치. 한 이미지에 여러 결함이 있으면 주 결함 기준.*

* **[2-1] 실제 발생하는 결함 유형 (주 결함 기준 비율)**
  - [v] 모서리/가장자리 찍힘(Chip·Notch) **약 50%** → 회색 사각 너트의 모서리·챔퍼 림 결손, 소형 너트의 V자 노치
  - [v] 관통 균열(Crack) **약 15%** → 녹 발생 너트에서 구멍~외곽까지 이어지는 균열선, 녹과 항상 동반
  - [v] 나사산 손상 **약 8%** → 나사산 입구 뭉개짐·찢김 (예: `synth_defect_10, 32, 65, 107, 120`)
  - [v] 녹·부식 → 균열과 동반되어 단독 비율 산정 불가
  - [v] 눌림/변형(Dent) **약 17%** → 아연도금 너트의 모서리 눌림·코팅 박리
  - [v] 긁힘(Scratch) **약 10% 미만** → 표면 긁힘·작은 찍힘 자국이 다른 결함에 동반
  - [ ] 이물 부착 → 관찰되지 않음
  - [ ] 데이터셋에 없는 유형(미탭, 편심, 치수 불량, 이종품, 뒤집힘) → 관찰되지 않음

* **[2-2] 불량률**
  - [ ] 1% 미만  - [ ] 1~5%  - [v] 5% 이상 → 데이터 비율 50% (클래스 균형을 위해 맞춘 값으로 보이며 실제 불량률은 판단 불가)

* **[2-3] 결함 크기 분포**
  - [v] 대형 결함 위주 → 일반 촬영 거리에서 찍힘·눌림은 약 30~120px, 균열은 폭 2~5px이지만 길이 100px 이상
  - [v] 미세 결함 존재 → 원거리 소형 촬영(약 21장)에서는 노치가 약 5~15px 수준으로 작아짐
  - [ ] 최소 검출 크기(mm) → 화소당 길이 기준이 없어 판단 불가

* **[2-4] 결함 발생 위치**
  - [v] 윗면(촬영면)에만 발생 → 전 이미지가 상면 촬영, 측면/뒷면 데이터 없음
  - [v] 특정 위치에 집중 → **모서리·외곽 가장자리**가 대부분, 다음으로 **나사산 입구**, 균열은 구멍↔외곽 방사 방향

* **[2-5] 판정 기준과 라벨링 주체**
  - [ ] 판정 주체 → 판단 불가
  - [v] 판정이 애매한 샘플 존재 → 결함이 매우 작거나 흐려서 육안 식별이 어려운 불량 이미지 다수 (예: `synth_defect_7, 20, 25, 87, 102`)
  - [ ] 결함 등급(치명/중/경) 구분 → 라벨 없음

## 3. 촬영 조건 (데이터 분포)

* **[3-1] 카메라 사양**
  - [ ] 모노크롬
  - [v] 컬러 → 파일은 3채널 RGB. 단 평균 채도 3 수준으로 대부분 무채색이며, **녹(갈색)·도금(청색) 판별에만 색 정보가 쓰임**
  - [v] 해상도 640×640, 종횡비 1:1 (원본 해상도는 판단 불가 — 업스케일 흔적 있음)
  - [v] 저장 포맷 PNG(무손실), 메타데이터 없음

* **[3-2] 촬영 거리·화각 고정 여부**
  - [ ] 카메라 고정, 부품 크기 일정
  - [v] **촬영 거리 비고정** → 부품 면적 6%~63%로 약 10배 차이. 불량 23장 / 정상 4장이 화면의 12% 미만(원거리)
  - [v] 부품이 화면 밖으로 잘리는 경우 있음 → 근접 촬영 이미지에서 다수 발생
  - [ ] 화소당 실제 길이(mm/px) → 기준 물체가 없어 판단 불가

* **[3-3] 배경**
  - [v] 배경 색: 흰색~밝은 회색 위주(배경 밝기 중앙값 약 210~220), 일부 진회색(118~140), 일부 연보라 톤 (예: `synth_defect_2, 62, 114, 125`)
  - [ ] 배경 오염·기름·흠집 → 관찰되지 않음 (무지 배경)
  - [ ] 부품 외 다른 물체 → 관찰되지 않음

* **[3-4] 조명 및 밝기 변동**
  - [v] 확산 조명 → 부드러운 그림자가 부품 한쪽으로 지며, 그림자 방향이 이미지마다 다름
  - [v] 밝기 변동 큼 → 배경 밝기 118~255
  - [v] 반사 포화 발생 → 260장 중 45장(약 17%)이 화면의 5% 이상 255 근처로 포화 (대부분 밝은 배경 포화)

* **[3-5] 선명도(초점·블러)**
  - [v] 정지 촬영 → 한 방향으로 늘어진 모션 블러는 관찰되지 않음
  - [v] **흐림 있음** → 불량 89장(68%), 정상 34장(26%)이 흐림. 초점 문제보다는 저해상도 업스케일 형태
  - ⚠ 정상/불량 간 화질이 다름 → 데이터 편향

* **[3-6] 부품 자세**
  - [ ] 지그로 위치·각도 고정
  - [v] 위치는 대체로 중앙, 각도 임의 → 부품 중심 좌표가 x 254~378, y 262~378px 범위(화면 중앙 ±60px), 각도는 0~360°
  - [ ] 완전 임의
  - [ ] 뒤집혀 들어오는 경우 → 판단 불가 (상면 모양이 대칭이라 구분 어려움)
  - [ ] 1프레임에 2개 이상/겹침 → 관찰되지 않음 (전부 1화면 1부품)

## 4. 데이터 수집 현황 (충족 여부)

*수집 계획 항목을 현재 데이터셋이 충족하는지로 기입.*

* **[4-1] 정상 데이터**
  - [ ] 품종별 정상품 200장 이상 → **미충족**: 1개 품종에 130장(고유 약 104장), 나머지 품종 0장
  - [ ] 로트·날짜·교대조 분산 → 정보 없음
  - [ ] 경계선 정상품 별도 구분 → 없음

* **[4-2] 불량 데이터**
  - [v] 찍힘·노치 20~30장 이상 → 충족 (약 65장)
  - [v] 눌림(도금) → 충족 (약 22장)
  - [ ] 균열+녹 → 경계선 (약 19장)
  - [ ] 나사산 손상 → **미충족** (약 10장)
  - [ ] 같은 개체 반복 촬영 기록 → **미충족**: 완전 중복 9장, 같은 너트를 각도/배경만 바꾼 유사 이미지 그룹이 다수 있으나 기록 없음

* **[4-3] 촬영 원칙**
  - [ ] 정상·불량 동일 조건 촬영 → **미충족** (품종·화질·거리 분포가 클래스별로 다름)
  - [ ] 원본 보존(리사이즈 금지) → **미충족** (업스케일 흔적)

* **[4-4] 메타데이터**
  - [ ] 부품 ID/로트/품종 코드 → 없음
  - [ ] 촬영 일시·설비·카메라 설정 → 없음
  - [ ] 결함 유형·판정자 → 없음
  - [ ] 결함 위치 표시 → 없음

* **[4-5] 라벨링 협조** → 판단 불가

## 5. 데이터 활용 판단

* **[5-1] 데이터 품질 판정**
  - [ ] 학습용으로 바로 사용 가능
  - [v] 정제 후 일부 사용 가능 → 스테인리스 회색 사각 너트(정상/찍힘 불량)는 클래스 간 조건이 비교적 유사
  - [v] 별도 도메인 분리 필요 → 아연도금·녹 너트는 정상 데이터가 없어 현재 상태로는 분류 학습에 부적합

* **[5-2] 정리 필요 항목**
  - [v] 완전 중복 9장 제거, 유사 이미지 그룹은 학습/검증 분할 시 같은 쪽으로 묶기
  - [v] 정상 데이터가 없는 품종(도금·녹) 제외 또는 해당 품종 정상 데이터 추가 확보
  - [v] 흐린 이미지 처리 방침 결정 (제외 / 정상에도 같은 열화 적용해 균형 맞추기)
  - [v] 원거리 소형 이미지(불량 23장 vs 정상 4장) 균형 맞추기 또는 부품 영역 크롭으로 크기 정규화
  - [v] 결함 유형 라벨(최소 이미지 단위) 추가

## 6. 현장 방문 시 지참·요청 목록

- [v] 데이터셋 대표 이미지 출력본 → 품종/결함 유형별 대표 예시 선정 완료 (1-2, 2-1의 파일명 참고)
- [ ] 측정 도구: 스케일 자/캘리퍼스, 그레이 카드
- [ ] 요청 자료: 부품 규격서, 불량 판정 기준서, 불량 이력, 한도 견본
- [ ] 실물 샘플 반출 (특히 **도금·녹 품종의 정상품**)
- [ ] 현장 카메라 시험 촬영 10~20장

---

## 7. 판단 불가 항목 (현장에서 반드시 확인)

| 항목 | 이유 |
| :--- | :--- |
| 실제 불량률, 판정 주체, 결함 등급 | 이미지에 운영 정보 없음 |
| 최소 검출 결함 크기(mm), 화소 분해능 | 기준 물체·카메라 정보 없음 |
| 방청유·먼지 허용 여부 | 데이터에 해당 사례 없음 |
| 뒤집힘 투입 여부, 측면 결함 | 상면 촬영만 존재 |
| 품종 전환 빈도, 로트별 편차 | 메타데이터 없음 |
